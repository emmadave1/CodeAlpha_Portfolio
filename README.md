# Alamzy — Personal Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript to showcase my skills, projects, and journey as a frontend developer.

Developed as part of the **CodeAlpha Frontend Development Internship**, this project demonstrates my understanding of responsive web design, interactive user interfaces, and fundamental JavaScript functionality.

## Overview

The portfolio introduces me as **Emma Dave, popularly known as Alamzy**, and provides visitors with an overview of my background, technical skills, selected projects, and professional links.

The website features a modern dark theme with purple accents, smooth scrolling, interactive navigation, and subtle animations.

## Features

* **Responsive Design:** Adapts to desktop, tablet, and mobile screen sizes.
* **Modern UI:** Dark-themed interface with purple accents and a clean visual hierarchy.
* **Hero Section:** Introduces me and provides quick links to my work and contact information.
* **About Section:** Shares my background, interests, and approach to learning and development.
* **Skills Section:** Highlights relevant web development technologies and tools.
* **Projects Showcase:** Displays selected projects with descriptions, technology tags, and links.
* **Mobile Navigation:** Includes a responsive navigation menu for smaller screens.
* **Scroll Animations:** Uses the Intersection Observer API to reveal content as visitors scroll.
* **Active Navigation:** Highlights the navigation link corresponding to the section currently in view.
* **Back-to-Top Button:** Allows visitors to return to the top of the page conveniently.
* **Dynamic Footer Year:** Automatically updates the copyright year using JavaScript.
* **Accessibility Considerations:** Includes navigation labels, semantic HTML, and support for reduced-motion preferences.

## Technologies Used

* **HTML5** — Semantic page structure and content.
* **CSS3** — Responsive layouts, styling, transitions, and animations.
* **JavaScript** — Interactive navigation, scroll behavior, section highlighting, and dynamic content.
* **Google Fonts** — Typography using Space Grotesk, DM Sans, and DM Mono.

## Getting Started

### Prerequisites

You need a modern web browser, such as Google Chrome, Microsoft Edge, or Mozilla Firefox.

For a more convenient development experience, you can use Visual Studio Code with the Live Server extension.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/emmadave1/CodeAlpha_Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CodeAlpha_Portfolio
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or launch it using Live Server.

No package installation or build process is required.

## Responsive Design

The website uses CSS media queries and flexible layouts to support different screen sizes.

The mobile navigation menu, project cards, skills grid, and other sections adjust to provide a more comfortable browsing experience on smaller devices.
